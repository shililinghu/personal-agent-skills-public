# personal-agent-skills-public

Reusable agent skills and technical reference templates.

This public edition contains reusable source only, with independent Git history. Read [PRIVACY.md](PRIVACY.md) before configuring it.

Original runtime configuration, personal data and media are intentionally absent. Install dependencies listed by the included package or requirements files and supply your own local settings. Examples are fictional.

## Usage

Work in `codex-skills/`. Each subdirectory contains a reusable SKILL.md and associated technical resources. Install selected skills in your own agent environment. Personal writing bindings, private taste models, messaging digests and local trust registries are excluded.
