# 高考志愿辅助填报自动填表 Skill

这是一个基于压缩包内志愿课讲义、笔记和 Excel 模板蒸馏出的 skill 包。

## 包含内容

- `SKILL.md`：主调度规则。
- `knowledge/`：填报原则、政策规则、定位方法、冲稳保、院校/专业/城市调研、决策评分、数据核验。
- `schemas/`：随包 Excel 模板的 sheet 结构与字段映射。
- `tools/`：自动填表工作流说明。
- `templates/`：用户信息采集、最终报告、风险清单模板。
- `resources/template_workbooks/`：原始 Excel 模板副本，供 agent 生成工作簿时使用。

## 使用方式

导入 skill 后，用户可以说：

> 我是 XX 省，XX 类，XX 分，位次 XX，本科线 XX。专业优先，不接受民办和中外合作。帮我生成一版志愿表。

Agent 应根据 skill 中的规则，生成：
- 已填好的 Excel 工作簿。
- 志愿方案复核报告。
- 待人工确认清单。

最终填报前，仍必须以省考试院系统和高校招生章程为准。
