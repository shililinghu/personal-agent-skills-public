# 示例工作流

用户输入：
- 2025 年，某省，物理类，600 分，位次 18000，本科线 450。
- 想优先专业，权重：专业 50%、城市 30%、院校 20%。
- 不接受民办和高收费，能接受省外，不接受冷门纯文科专业。

Agent 操作：
1. 计算线差：150。
2. 判断分段：若批次排名在 15%-80%，主用同位分法，位次/线差复核。
3. 要求或读取一分一段表，换算 2024、2023、2022 同位分。
4. 用同位分上下扩展形成初始院校池。
5. 导入往年录取数据，计算满足次数、录取分-同位分均值。
6. 生成冲稳保初判。
7. 对候选院校补充学校、专业、城市字段。
8. 生成专业+院校或院校+专业组决策表。
9. 输出工作簿和风险报告。

输出提醒：
- 如果缺一分一段表，只能先做线差/位次临时判断。
- 如果缺招生章程，所有调剂/专业规则结论都标为待核验。
