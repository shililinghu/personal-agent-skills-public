# 随包工作簿结构与字段用途

## 1. 初选模板：线差_位次_同位分初选模板.xlsx

### 个人线差数据记录
字段：年份、省控线（批次线）、高考总分、线差、线差最低值、线差最高值。

自动填充：
- 线差 = 高考总分 - 省控线。
- 默认区间可按用户或课程策略生成：低分压线可向上 10-15、向下 20；冲稳保细分见规则。

### 线差院校数据表
字段：学校名称、年份、线差最低值、线差最高值、线差、线差判断、多年平均线差、三年满足区间次数、线差均值 - 当年线差、冲稳保推荐判断、冲稳保标签。

自动填充：
- 线差判断：往年院校线差是否落入个人线差区间。
- 多年平均线差：同一学校多年份线差平均。
- 满足次数：同一学校过去 2-3 年落入区间的次数。
- 推荐判断：按线差冲稳保规则初判。

### 个人位次数据记录
字段：年份、位次、位次最小值、位次最大值。

自动填充：
- 位次区间由考生位次和分段策略生成。

### 位次院校数据表
字段：学校名称、年份、位次最小值、位次最大值、位次、位次判断、多年平均位次、三年满足区间次数、（当年位次 - 多年平均位次）/ 当年位次、冲稳保推荐判断、冲稳保标签。

自动填充：
- 位次判断：院校往年录取位次是否落入区间。
- 位次差比例 = (考生位次 - 多年平均位次) / 考生位次。
- 推荐判断按位次法冲稳保规则。

### 个人同位分数据记录
字段：年份、年份标签、同位分、位次、同位分下限、同位分上限。

自动填充：
- 同位分来自一分一段表换算，不能凭空生成。
- 下限/上限默认围绕同位分扩大，初选常用上下 25 分；冲稳保细分另算。

### 同位分院校数据表
字段：学校名称、年份、同位分下限、同位分上限、录取分数、同位分判断、录取分-当年同位分、三年满足区间次数、（录取-同位分）均值、冲稳保推荐判断、冲稳保标签。

自动填充：
- 同位分判断：院校录取分是否落入当年同位分区间。
- 录取分-同位分：用于判断冲稳保。

## 2. 决策模板：志愿课系统数据表.xlsx

### 院校记录表
字段：学校名称、冲/稳/保、省市、城市、城市级别、城市重要性、院校重要性、专业重要性、城市发展评分、城市生活评分、城市规划评分、城市意愿评分、民办/公办、批次、学校头衔、学校类型、环境评分、学习评分、生活评分、头衔评分、优势专业 1-6、冲专业 1-4、稳专业 1-4、保专业 1-4、SourceID。

建议扩展字段：SourceURL、查询日期、可信度、待人工确认、风险标签、备注。

### 专业记录表
字段：专业名称、专业门类、能力要求、就业方向、选科要求、喜欢的原因、兴趣意愿指数、能力匹配指数、未来发展指数、大学生活指数、SourceID。

建议扩展字段：专业代码、核心课程、培养目标、行业趋势、红绿牌/风险、SourceURL、查询日期、待人工确认。

### 重要性排序 / 三要素重要性排序
字段：类别、重要性、SourceID、判断逻辑/判断依据。

自动校验：院校、专业、城市三项权重合计必须等于 1 或 100%。

### 「旧高考」传统志愿决策总表
核心字段：院校名称、冲/稳/保、民办/公办、批次、学校头衔、近三年录取数据、院校评分、院校权重、城市评分、城市权重、冲/稳/保专业组内专业评分、专业综合评分、专业权重、志愿综合总分、确认选择。

适用：旧高考或传统院校志愿。必须重点复核专业录取规则和调剂。

### 「新高考」专业+院校决策总表
核心字段：专业名称、专业评分、近三年录取数据、专业权重、冲/稳/保、院校名称、院校评分、院校权重、城市评分、城市权重、志愿综合总分、确认选择。

适用：专业+院校模式。重点检查选科、体检、特殊要求。

### 「新高考」院校+专业组决策总表
核心字段：院校名称、冲/稳/保、院校评分、城市评分、专业组编号、选科要求、近三年录取数据、组内冲/稳/保专业 1-3、统计入档、专业综合评分、专业权重、志愿综合总分、确认选择。

适用：院校+专业组模式。必须核验专业组内所有专业及调剂风险。
