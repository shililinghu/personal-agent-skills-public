# 更新记录

## v1.4.0

### 核心变化

- 新增 `knowledge/internet_research_before_scoring.md`，明确“联网信息整理必须先于用户评分”。
- 新增 `templates/internet_research_pack_template.md`，用于生成院校、专业、城市资料卡和来源候选清单。
- 更新 `SKILL.md`：当用户已给出候选学校/专业/城市时，不得直接输出空白用户评分表，必须先输出联网检索任务、资料卡、已用来源、可选来源、待核验信息。
- 更新 `templates/research_card_template.md`：加入检索状态、检索任务、可选来源清单、评分前置检查。
- 更新飞书多维表格结构：新增“联网检索任务表”和“可选信息来源清单”。
- 更新 payload schema：新增 `research_tasks` 与 `source_candidates`。

### 行为约束

Agent 负责找信息、整理信息、汇总信息和列来源；用户负责价值判断和 1-5 分评分。

用户评分表中的 “Agent 提供的信息摘要” 必须来自已整理资料卡。没有资料支撑时必须写“资料不足，建议先核验”，不能让用户盲评，也不能要求用户自行查资料。

## v1.3.0

### 核心变化

- 修正定位方法选择逻辑，避免 Agent 因“有位次”而直接选择位次法。
- 新增 `knowledge/positioning_method_rules_from_training.md`，明确训练文件中的分段规则。
- 更新 `SKILL.md` 和 `templates/method_selection_rationale.md`，要求每次方法选择都输出训练文件依据、当前已知数据、计算过程和禁止理由检查。
- 更新飞书多维表格、报告模板、决策记录模板和 payload schema。

### 行为约束

方法选择必须依据训练文件规则：普通场景为“前15%位次比例法、15%-80%同位分法、后20%线差数值法”；二本/二批次场景为“15%高分段位次比例法不能用、最后20%线差法可以用、1%-80%使用同位分法且定位应使用批次内真实排名”。

Agent 不得编造省份数据稳定、第三方数据充分、同分人数多、往年数据已公开等理由。缺少参考总量或批次内排名时，必须输出待补充，不得硬选主方法。


## v1.2.0

### 核心变化

- 新增“定位方法选择说明”模块。
- 要求 Agent 在初筛前说明为什么采用位次法、同位分法、线差法或组合定位。
- 新增 `templates/method_selection_rationale.md`。
- 新增“定位方法选择说明表”字段结构。
- 更新飞书报告模板、决策记录模板和 payload schema。

### 行为约束

Agent 不得只给出“用了位次法/同位分法/线差法”的结论，必须说明：选用原因、另外方法不作为主方法的原因、适用条件、方法风险、缺失数据和对冲稳保区间的影响。

## v1.1.0

### 核心变化

- 明确区分 Agent 信息整理职责与用户评分职责。
- 新增“信息整理与评分责任边界”。
- 新增 AI 信息整理表、用户评分表、权重与汇总表。
- 新增用户评分口径表、信息整理卡模板、评分汇总模板。
- 修改最终志愿方案表：主观评分不再由 Agent 自动生成，缺失时显示“待用户评分”。
- 更新 payload schema，加入 research_cards、user_score_records、score_summary。

### 行为约束

Agent 应尽可能完整地查找和整理院校、专业、城市信息，但生活环境、专业兴趣、城市喜欢程度、家庭承受感、后悔风险等主观项必须由用户评分。
