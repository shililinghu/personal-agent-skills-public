# 高考志愿决策助手（单用户飞书档案版｜联网资料卡先行 + 用户评分版）

这是一个用于高考志愿填报辅助的 Skill 包。它把考生咨询过程整理成“单用户独立档案包”，并为飞书文档/多维表格写入提供结构化输出规范。

## 适用场景

- 考生和家长进行高考志愿咨询
- 志愿咨询老师整理单个考生方案
- 飞书机器人为每个用户创建独立志愿档案
- 后端服务将咨询结果写入飞书文档或多维表格

## 核心功能

1. 收集用户基础信息
2. 建立不可接受清单
3. 解释专业真实含义和风险
4. 生成定位方法选择说明，解释为什么采用位次法、同位分法、线差法或组合定位
5. 判断院校、专业组、校区、学费、调剂等因素
6. 审查特殊类型志愿风险
7. 生成冲、稳、保、慎选方案
8. 在用户评分前，联网整理院校、专业、城市信息和证据来源
9. 列出已用来源和可选信息来源，标注官方/半官方/经验参考
10. 生成用户评分表，由用户完成主观评分
11. 根据用户评分和权重自动汇总排序
12. 生成最终决策记录和单用户飞书档案包 payload


## v1.4 联网资料卡先于用户评分

本版本修正“先给空评分表、让用户自己查资料”的问题：

- 当候选学校、专业、城市已明确时，Agent 必须先联网检索并整理资料卡。
- Agent 需要主动列出院校、专业、城市、生活环境、风险信息。
- Agent 需要列出已用来源和可选信息来源，区分官方、半官方、公共服务和经验参考。
- 用户评分表必须引用资料卡摘要；没有资料支撑的评分项要标注“资料不足，建议先核验”。
- 用户仍然负责主观评分，Agent 只负责找信息、整理信息、汇总计算和风险提示。

## v1.3 定位方法选择纠偏

本版本把“定位方法选择说明”改成训练文件规则驱动：

- 普通场景：高前15%使用位次比例法；中15%-80%使用同位分法；低后20%使用线差数值法。
- 二本/二批次场景：15%高分段位次比例法不能用；最后20%线差法可以用；1%-80%均使用同位分法，且应使用批次内真实排名。
- 不能因为“用户提供了位次”就直接选择位次法。
- 不能把“某省数据稳定”“第三方数据充分”“同分人数多”等未核验证据写成方法选择原因。
- 如果缺少参考总量、批次内真实排名或一分一段表，必须写“待补充”，不得强行判断分段。

## v1.2 定位方法选择说明

在生成候选院校池和冲稳保之前，Agent 必须输出“定位方法选择说明”。它需要说明本次为什么采用位次法、同位分法、线差法或组合定位，并解释另外方法为什么只作为辅助或暂不使用。

该说明只属于客观定位逻辑，不是用户主观评分，也不能代替招生计划、专业组、招生章程和最终风险审查。

## v1.1 评分责任边界

本版本明确区分“信息整理”和“价值评分”：

- AI/Agent 负责：查找信息、整理信息、摘录来源、标注核验状态、生成候选项、生成风险提示、生成用户评分表、汇总用户评分、计算权重总分、输出最终报告。
- 用户负责：生活环境接受度、城市偏好、专业兴趣、专业学习内容接受度、院校认可度、调剂接受度、家庭承受感、后悔风险等主观评分。
- 如果用户没有打分，Agent 不得自行补分，只能填写“待用户评分”。
- Agent 可以给出客观风险等级或事实摘要，例如“招生计划减少”“专业组内存在用户排除专业”“往年位次波动较大”，但不得把这些事实伪装成用户偏好分。

## 飞书设计原则

本 Skill 不默认创建公共用户数据总表。每个考生拥有一个独立档案包。

建议档案包结构：

- 志愿填报决策报告
- 定位方法选择说明表
- 候选院校表
- 专业理解表
- 证据来源表
- 风险审查表
- 最终志愿方案表
- 版本记录表

后台可保留一个极简索引表，但不要保存详细分数、位次、预算、偏好、志愿方案等敏感内容。

## 文件说明

- `SKILL.md`：主 Skill 说明，可直接作为导入核心。
- `skill.json`：Skill 元信息。
- `templates/`：飞书文档、多维表格模板、联网信息整理包模板。
- `contracts/`：后端写入飞书时使用的数据结构规范。
- `examples/`：示例 payload。

## 接入方式

典型系统结构：

用户对话 → Skill 分析 → 生成 archive payload → 后端服务 → 飞书文档/多维表格 → 返回用户专属链接

如果当前环境没有飞书 API 工具，Skill 只能生成结构化数据和报告正文，不能声称已经创建飞书文件。

## 合规提醒

- 不承诺录取结果。
- 不伪造官方来源。
- 不把未核验信息说成已核验。
- 最终填报前必须核验官方信息。
- 档案包默认只分享给用户本人或授权对象。
