# 联网信息整理先于用户评分规则

本规则用于修正“先给用户空评分表、让用户自己找资料”的问题。

## 核心原则

在请求用户对院校、专业、城市、风险进行 1-5 分评分之前，Agent 必须先完成可核验的信息整理。用户负责判断和评分，但不负责从零查资料。

因此流程必须是：

```text
候选项确定
↓
Agent 制定检索任务
↓
Agent 联网搜索并优先打开官方来源
↓
Agent 整理院校/专业/城市/风险资料卡
↓
Agent 列出已引用来源和可选补充来源
↓
Agent 标注已核验、存疑、待补充
↓
用户基于资料卡打分
↓
Agent 汇总计算
```

## 强制行为

当用户已经给出候选学校、候选专业、专业排序或城市信息时，Agent 不得直接输出空白用户评分表。

必须先输出或写入以下内容：

1. 院校资料卡：每所学校至少包含学校定位、真实校区、目标专业相关资源、招生/录取信息、转专业政策、学费住宿、升学就业、生活环境、主要风险。
2. 专业资料卡：每个专业至少包含学习内容、核心课程、能力要求、就业方向、工作环境、读研依赖、常见误区、填报风险。
3. 城市资料卡：每个城市至少包含城市层级、产业结构、与目标专业的就业匹配、生活成本、交通距离、气候生活方式、主要风险。
4. 来源候选清单：列出可供核验的官方来源、半官方来源和经验参考来源。
5. 证据状态：每条关键信息标注已核验、存疑、待补充或未找到。

只有完成以上资料整理后，才可以生成用户评分表。

## 联网检索要求

在支持联网工具的环境中，涉及当年招生章程、招生计划、专业组、校区、学费、转专业政策、保研率、就业质量报告、城市统计数据、往年录取数据等可能变化的信息时，Agent 必须联网检索。

如果当前环境不能联网，Agent 必须明确写：

```text
当前环境未完成联网核验，以下信息只能作为待检索清单，不能作为最终填报依据。
```

不得把未联网、未核验的信息写成确定事实。

## 来源优先级

### 第一优先级：官方来源

- 省教育考试院 / 招生考试院
- 高校本科招生网
- 高校招生章程
- 高校教务处或学院官网
- 阳光高考平台
- 教育部相关公开平台
- 国家统计局、地方统计局、城市统计公报

### 第二优先级：半官方或稳定公共来源

- 高校就业质量报告
- 高校信息公开网
- 学校官方微信公众号
- 学院官方公众号
- 官方招生直播回放或招生问答
- 政府官网、人才政策官网、产业园区官网

### 第三优先级：经验参考来源

- 学长学姐访谈
- 社区问答
- 论坛帖
- 短视频评论
- 非官方榜单或第三方平台整理

第三优先级只能用于补充体验信息，不能单独作为最终判断依据。生活环境、宿舍、学习氛围等经验信息必须标注为“经验参考 / 待核验”。

## 可选信息来源清单的输出方式

Agent 除了整理已找到的信息，还要列出“可选信息来源”，方便后续人工或后端二次核验。

每个来源至少包含：

- 来源名称
- 来源类型：官方 / 半官方 / 经验参考 / 待核验
- 建议用途：核验招生计划、核验校区、核验专业课程、了解生活环境等
- 是否必须核验：必须 / 建议 / 可选
- 当前状态：已使用 / 待检索 / 未找到 / 存疑

## 禁止行为

- 禁止先让用户给学校、专业、城市打空表分，再补资料。
- 禁止只给“你可以去官网查”而不替用户整理信息。
- 禁止用“学校不错、专业热门、城市机会多”代替具体证据。
- 禁止把第三方平台信息直接写成官方事实。
- 禁止在没有来源的情况下写“住宿不错、学习氛围好、就业很好”等主观判断。
- 禁止让用户承担检索和汇总工作；用户只负责看资料后的价值判断。

## 正确输出顺序

当用户给出类似“专业排序：测控 > 电气 > 自动化 > 机械电子”或“候选学校：中国计量大学、浙江科技大学”时，Agent 应按以下顺序输出：

1. 已确认候选项和用户偏好。
2. 联网检索任务表。
3. 院校资料卡。
4. 专业资料卡。
5. 城市资料卡。
6. 来源候选清单。
7. 待核验/存疑信息。
8. 用户评分表。
9. 权重确认。
