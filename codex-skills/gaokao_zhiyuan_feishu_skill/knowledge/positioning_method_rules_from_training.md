# 定位方法选择规则（来自训练文件）

本文件只整理训练文件中关于“位次法 / 同位分法 / 线差法”的方法选择逻辑，用于约束 Skill 输出。

## 1. 三种方法的基础含义

### 位次法 / 位次比例法
- 先确定今年位次。
- 考察过去 2-3 年录取表中录取位次相近的高校名单。
- 标记过去 2-3 年中位次相对稳定且重复出现的高校名单。
- 位次法的冲稳保用百分比衡量。

### 同位分法 / 等位分法
- 先确定今年位次。
- 通过位次换算到过去年份对应的同位次分数。
- 考察过去 2-3 年录取表中与同位分相近的高校名单。
- 训练文件中的表达：同位分定位法 = 结合位次 + 线差的核心；位次定位 + 分数拉区间。

### 线差法
- 先确定今年分数与批次线之间的线差。
- 考察过去 2-3 年录取表中线差相近以及线差稍微小于今年自己线差的高校名单。
- 更适合低分段、压线附近、保批次判断。

## 2. 普通场景的方法选择硬规则

训练文件给出的使用建议：

| 分段 | 主方法 |
|---|---|
| 高：前 15% | 位次比例法 |
| 中：15%-80% | 同位分法 |
| 低：后 20% | 线差数值法 |

执行要求：
- 不能因为“用户提供了位次”就直接选择位次法。
- 先判断考生处在参考群体的前 15%、15%-80%、后 20% 中哪个区间。
- 若缺少参考总量或批次内真实排名，必须标为“待判断/待补充”，不能硬选主方法。

## 3. 二本 / 二批次场景的特殊规则

训练文件给出的二本/二批次使用建议：

1. 15% 高分段的位次比例法不能用。
2. 最后 20% 的线差法可以用。
3. 1%-80% 均使用同位分法，且定位应该是批次内的真实排名。

执行要求：
- 二本/二批次不能直接套普通高分段的位次比例法。
- 必须优先判断“批次内真实排名”，而不是只看全省位次。
- 若没有批次内真实排名或可换算数据，则输出“待补充”，不要假装已经判断。

## 4. 允许说的依据

方法选择说明只能基于：
- 用户明确提供的数据：分数、位次、批次线、一分一段表、批次内排名、往年录取数据。
- 训练文件明确写出的规则。
- Agent 实际查到并已写入证据来源表的信息。

## 5. 禁止说的依据

除非用户提供或 Agent 实际查证并留证据，否则不得写：
- 某省每年一定公布完整数据。
- 某省同分人数多，所以必须用某方法。
- 某年份某院校数据充分。
- 第三方平台数据充分或可交叉验证。
- 用户属于中间分数段、高分段或低分段，但没有给出参考总量/批次内排名计算过程。
- “位次比分数更准确”作为单独选择位次法的理由。训练文件的主规则是分段选择，不是泛泛地位次优先。
